# Shanti Jewellers — Starter scaffold

This repository contains a starter Next.js + Tailwind project and a Supabase schema to build the Shanti Jewellers website and admin panel.

What is included
- Next.js public site scaffold (homepage, admin scaffold)
- Tailwind CSS setup
- A SQL file to create the database schema and seed sample categories/products for Supabase
- README with setup & deployment instructions

Next steps
1. Install dependencies: `npm install`
2. Create a Supabase project and run the SQL in `lib/supabase.sql` (see README).
3. Add environment variables (see README) and run `npm run dev`.
